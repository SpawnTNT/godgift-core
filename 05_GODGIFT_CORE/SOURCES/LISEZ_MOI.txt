GodGift Core, le nœud de la chasse de L’Ange de l’Eau (version d’essai)

  1. Décompressez l’archive (Windows : clic droit > Extraire tout).
  2. Double-cliquez sur « Commencer ici ».
  3. Choisissez votre appareil : Windows, Mac, Linux, Raspberry Pi, téléphone, ou sans installer.
     La page détecte le vôtre et affiche les étapes.

GodGift Core suit les 24 coffres sur la chaîne Bitcoin, vérifie tout lui-même, fait chasser
hors ligne et fait devenir compagnon ; quand vous trouvez, il vide lui-même le coffre vers votre
adresse de réception signée. Aucune donnée personnelle ; aucune clé conservée.
Le trésor part tout seul dans la fenêtre de l’application installée, ouverte par son icône.
Ailleurs (votre navigateur, la version web, une fenêtre rechargée), GodGift Core vous fait d’abord
retaper 16 caractères de votre adresse de réception, en deux morceaux tirés au hasard et masqués
à l’écran, lus dans votre propre portefeuille ; sans installer, il ne récupère aucun trésor.

L’installateur vérifie chaque fichier contre fichiers/SHA256SUMS, ne copie que les fichiers de
cette liste et affiche l’EMPREINTE DU PROGRAMME. Comparez-la à celle que publie l’auteur, ou
déposez le fichier téléchargé sur angedeleau.com/verifier-installateur. À la sortie officielle,
l’auteur désignera la version publiée par un message signé qui en donne l’empreinte ;
recompiler_et_comparer.py (dans les sources) refait le programme et compare, comme on vérifie Bitcoin Core.

INSTALLER, EN BREF
  Windows             : double-clic sur « Installer (Windows) », puis Installer.
  Mac                 : glisser « GodGift Core » dans Applications ; la première fois,
                        Réglages Système > Confidentialité et sécurité > Ouvrir quand même.
  Linux, Raspberry Pi : double-clic sur « Installer (Linux, Raspberry Pi) »
                        (ou : sudo apt install "./Installer (Linux, Raspberry Pi).deb").
                        Autres distributions : sh fichiers/installer_linux.sh
  Téléphone           : ouvrir app.angedeleau.com, puis « Ajouter à l’écran d’accueil ».
                        Pour récupérer un trésor, l’application installée sur un ordinateur
                        reste la voie la plus sûre.

DÉSINSTALLER
  Windows : Paramètres > Applications > Applications installées > GodGift Core > Désinstaller.
  Mac     : mettre GodGift Core à la corbeille.
  Linux   : logithèque, ou sudo apt remove godgift-core.
  GodGift Core ne conserve aucune clé.
